# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

The runtime uses TypeScript, React, Vite, json-render, Zod, and a local Node CLI/server.

## Users

People building apps with coding agents who discover requirements by discussing ideas and trying interfaces.

## Product Purpose

Help users understand product journeys, uncover missing requirements, and try interactive prototypes before expensive implementation.

## Capabilities and Constraints

Proactive discovery, persistent feature decisions, JSON-driven prototypes, expandable component catalog, simulated interactions, feedback to the active coding agent, and readable plan exports. Formative is independent of Planboard. Backend behavior is simulated. No model account is required beyond the host coding agent.

## Brand Commitments

Formative components follow a shared design standard, with a restrained default theme with light and dark variants and a clear separation between review tools and the prototype.

## Product Principles

- Discover omissions and unnecessary scope alike.
- Keep user decisions distinct from agent proposals.
- Let users learn by trying complete actions.
- Preserve work and provide recovery on failure.
- Reuse consistent components and load only relevant definitions.
